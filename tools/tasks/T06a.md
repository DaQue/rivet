## Rules for `RefName::parse` (git is the oracle)

Reject with `Error::InvalidRefName { name, reason }` (check the variant's exact fields in
`error.rs` and use a short static reason), in this order:

1. empty, or exactly `@`;
2. any byte `< 0x20`, `0x7f`, or a space; any of `~ ^ : ? * [ \`;
3. the two-byte sequences `..` or `@{` anywhere;
4. split on `/`: no empty component (so no `//`, no leading/trailing `/`); no component beginning
   with `.`; **no component ending with `.lock`, and no component ending with `.`** (git rejects
   `refs/heads/a/b.` — verified, not just the whole name); 
5. fewer than one `/` unless the name is a one-level **all-caps pseudo-ref** — every byte is ASCII
   uppercase, a digit or `_` (`HEAD`, `MERGE_HEAD`, `AUTO_MERGE`). This exception is Rivet's, not
   git's: plain `git check-ref-format HEAD` exits 1. Do not "fix" it to match git; `RefName::head()`
   depends on `HEAD` being valid.

Bytes need not be UTF-8. Do not allocate a `String` to validate.

`from_bytes` delegates to `parse`; `from_bstring` validates the moved `BString` and stores it
without a second copy. `branch(short)` builds `refs/heads/<short>` and validates the *whole*
result; `tag` does `refs/tags/`; `remote_tracking(remote, branch)` does
`refs/remotes/<remote>/<branch>` (the branch may contain `/`). `head()` constructs the literal
`HEAD` without parsing.

`prefix()`: `Branch → Some(b"refs/heads")`, `Tag → Some(b"refs/tags")`,
`Remote → Some(b"refs/remotes")`, `Note → Some(b"refs/notes")`, `Head`/`Other → None`.
`as_str()`: `"head" "branch" "tag" "remote" "note" "other"`.

`category()` is a pure prefix test on the stored bytes: `HEAD` → `Head`; `refs/heads/` → `Branch`;
`refs/tags/` → `Tag`; `refs/remotes/` → `Remote`; `refs/notes/` → `Note`; else `Other` (this
includes one-level pseudo-refs other than `HEAD`, e.g. `MERGE_HEAD`). The prefix must be followed
by at least one byte.

`short_name()`: strip the category's prefix **and its slash**; `Head` and `Other` return the whole
name. `is_head`/`is_branch`/`is_tag`/`is_remote` are category/predicate tests.
`is_pseudo_ref()`: no `/` anywhere.

`file_path(git_dir)`: `git_dir.join(name)`. `reflog_path(git_dir)`: `git_dir.join("logs").join(name)`.
Convert bytes to a path losslessly on Unix (`std::os::unix::ffi::OsStrExt`) and lossily on other
targets (`String::from_utf8_lossy`), with `#[cfg]`. Never `unwrap` on the conversion.

`impl fmt::Display`: `write!(f, "{}", self.0.escape_bytes())` if `bstr`'s `escape_bytes` is
available; otherwise `write!(f, "{}", self.0)` — it must never panic on non-UTF-8. This is the one
lossy place; do not round-trip through it.

## Tests (in `name.rs`)

1. `git_check_ref_format_agrees` — for every name **containing a `/`** in a table of valid and
   invalid names, run `git check-ref-format <name>` (pass bytes via `OsStrExt` on Unix) and assert
   `RefName::parse` accepts iff git exits 0. Cover at least: `refs/heads/main`,
   `refs/heads/feature/x`, `refs/tags/v1.0`, `refs/remotes/origin/HEAD`, `refs/notes/commits`,
   `refs/heads/fix-1.2`, `refs/heads/a.b`, `refs/heads/caf\xe9` (valid);
   `refs/heads/`, `/refs/heads/main`, `refs//heads/main`, `refs/heads/.h`, `refs/heads/x.lock`,
   `refs/heads/a.lock/b`, `refs/heads/a..b`, `refs/heads/a b`, `refs/heads/a~b`, `refs/heads/a^b`,
   `refs/heads/a:b`, `refs/heads/a?b`, `refs/heads/a*b`, `refs/heads/a[b`, `refs/heads/a\\b`,
   `refs/heads/a.`, `refs/heads/a/b.`, `refs/heads/a@{1}`, `refs/heads/a\x7f`,
   `refs/heads/a\x01` (invalid). Skip the whole test with a message if `git --version` fails.
2. `one_level_pseudo_refs_are_allowed` — `HEAD`, `MERGE_HEAD`, `FETCH_HEAD`, `AUTO_MERGE` parse;
   `main`, `refs`, `head` (lowercase) do not. State in a comment that plain `git check-ref-format`
   rejects these four and that the exception is documented.
3. `constructors_prefix_correctly` — `branch("feature/x")` → `refs/heads/feature/x`;
   `tag("v1.0")`; `remote_tracking("origin", "feature/x")` → `refs/remotes/origin/feature/x`;
   `RefName::head()`; each round-trips through `as_bytes`/`from_bytes`.
4. `category_and_short_name` — the six categories, `short_name` for each, `Other` includes
   `MERGE_HEAD`; `is_pseudo_ref` true for `HEAD`/`MERGE_HEAD`, false for `refs/heads/main`.
5. `paths_are_built_in_the_right_place` — `refs/heads/main` → `<git>/refs/heads/main` and
   `<git>/logs/refs/heads/main`; `HEAD` → `<git>/HEAD` and `<git>/logs/HEAD`.
6. `display_does_not_panic_on_non_utf8` — a name with `\xe9` renders and contains a replacement or
   escape; no panic.

Assertions must fail if a rule is dropped (e.g. deleting the `.lock` check must fail test 1).
No test may be weakened to accommodate an implementation shortcut.
