# T05b — the `Index` container: load, parse, checksum, serialise, atomic write (2 of 4)

## Goal

Implement the **container** half of `crates/rivet-core/src/index/mod.rs`: read a real `.git/index`
written by git, verify it, keep its extensions verbatim, and write one back that git accepts

do not reimplement or edit them.

## Verification sequence for `parse` (order matters)

1. `data.len() >= 12 + format.len()`, else `CorruptIndex { offset: data.len(), reason: … }`.
2. Magic `data[0..4] == b"DIRC"` else `BadIndexSignature { found: [u8;4] }`.
3. Version = big-endian u32 at 4. `IndexVersion::from_u32` → **reject `V4` here** with
   `UnsupportedIndexVersion { version: 4 }` (from_u32 accepts 4 so it can be reported).
4. Count = big-endian u32 at 8.
5. Parse `count` entries with `IndexEntry::parse(format, version, &data[offset..])`, advancing by
   its `consumed`. **Do not `Vec::with_capacity(count)`**: a hostile count must fail on the first
   truncation, not allocate 4 GiB.
6. Extensions until `offset == data.len() - format.len()`. Each: 4-byte signature, big-endian u32
   payload length, payload. Lengths are not padded. If a signature is **not** optional
   (`IndexExtension::is_optional`) and is not one of `TREE`, `REUC`, `UNTR`, `link`, refuse with
   `CorruptIndex { offset, reason: "unknown mandatory index extension" }`. Optional unknowns are
   **kept verbatim** (round-trip rule).
7. Checksum: `format.hasher()` over `data[..data.len()-format.len()]`; stored = the last
   `format.len()` bytes as `ObjectId::read`. Mismatch → `BadIndexChecksum { expected: stored,
   actual: computed }`.

`Index::to_bytes`:

* version = `V3` iff **any** entry's `flags.is_extended()` is set, else `V2`. Never write `V4`.
* write entries **in the order stored** — do not sort here (`Index::sort` is explicit; sorting hides
  a caller bug).
* write extensions in stored order, payload lengths big-endian, no padding.
* append the fresh checksum. The returned `Vec` includes it.

`Index::write`:

* lock file = the index path's file name + `.lock` in the same directory (`.git/index` →
  `.git/index.lock`). If the lock exists → `Error::LockHeld { path: lock }` (path as `BString`).
* write, flush, `sync_all` if cheap, set mode **0644** on Unix (mirror the pattern in
  `src/odb/loose.rs`), then rename over the index. On any failure remove the lock and return
  `IoAtPath { path, source }` (check the variant's exact fields in `error.rs`).
* Never leave the lock behind on success.

`load` must reproduce `IoAtPath` for an unreadable existing file, and must not treat
`NotFound` as anything but an empty index.

## Tests (append to `tests/index_git_differential.rs`; real git is the oracle)

Helpers: a `git(dir, args)` that asserts success and returns stdout, plus `git_env` that sets
`GIT_INDEX_FILE` for the `ls-files` checks. Skip with a message when `git --version` fails.

1. `git_written_index_round_trips_byte_exactly` — `git init`; files including `a`, `a.txt`,
   `dir/nested.txt`, an executable and a symlink; `git add -A`; `git write-tree` (this adds the
   `TREE` extension). Read `.git/index`: `Index::parse(Sha1, &raw)` → `to_bytes(Sha1) == raw`,
   **byte for byte**, extensions included. Assert version `V2` and the entry count.
2. `v3_with_skip_worktree_round_trips` — `git add` then `git update-index --skip-worktree <file>`;
   parse (version `V3`), `to_bytes` equals the file exactly, and the reloaded entry keeps the
   extended bit and word.
3. `written_index_is_accepted_by_git` — parse the git index, write it to a fresh path with
   `Index::write`, then run `git ls-files --stage` with `GIT_INDEX_FILE=<that path>` in the same
   repo and assert the output equals the output for the original index. Also assert `git ls-files -v`
   agrees for the v3 skip-worktree case.
4. `empty_and_missing_index` — `Index::load(<missing>)` is empty, `V2`; `Index::new().to_bytes` is
   accepted by `git ls-files` with `GIT_INDEX_FILE` (exit 0, empty output).
5. `checksum_mismatch_is_detected` — flip the last byte → `BadIndexChecksum`, no panic.
6. `bad_signature_v4_and_truncation` — header magic changed → `BadIndexSignature`; version field set
   to 4 → `UnsupportedIndexVersion { version: 4 }`; body cut in half → `CorruptIndex`.
7. `unknown_mandatory_extension_refused_optional_kept` — splice an extension before the trailer:
   `ZZZZ` + length 0 → `CorruptIndex`; `zzzz` + length 3 + payload → parses, round-trips, and the
   unknown payload is still present in `extensions()`.
8. `write_respects_the_lock_file` — create `<path>.lock` → `write` returns `LockHeld`; after
   removing it, `write` succeeds and the lock is gone.
9. `sha256_index_round_trips` — `git init --object-format=sha256`, `git add`, parse with `Sha256`,
   `to_bytes` byte-identical, and `git ls-files --stage` with `GIT_INDEX_FILE` agrees.

Do not weaken a T05a test. Tests must fail if the checksum check, the extension order, the id width
or the v3/v2 selection changes.
