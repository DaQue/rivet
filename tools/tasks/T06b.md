## `RefTarget`

* `oid()` — `Direct` → `Ok`; `Symbolic(name)` → `Error::SymbolicRef { name: name.as_bstring().clone() }`.
* `symbolic_target()` — `Symbolic` → `Ok(&RefName)`; `Direct` → `Error::SymbolicRef { name: oid.to_hex() }`
  (the enum carries no ref name; the hex is the only identifier available — say so in the report).
* `is_symbolic` / `is_direct` — plain matches.
* `to_bytes(format)` — `Direct` → lowercase hex at the format's width + `b"\n"` (`ObjectId::to_hex`);
  `Symbolic` → `b"ref: "` + name bytes + `b"\n"`. Exact bytes, verified against git.

## `RefLock`

* `acquire(git_dir, name)` → target = `name.file_path(git_dir)`; delegate to `acquire_path`.
* `acquire_path(path)` → parent directories created if missing; lock path = same directory,
  file name + `".lock"`; create **exclusively** (`OpenOptions::create_new`). `AlreadyExists` →
  `Error::LockHeld { path: lock }`; other errors → `Error::IoAtPath` (check its exact fields).
  Store `path`, `target`, `armed = true`.
* `path()` → `&self.path`.
* `write_and_commit(data)` → truncate + write all of `data` to the lock file, then `commit()`.
* `commit()` → `std::fs::rename(lock, target)`; on success `armed = false`; on failure
  `IoAtPath { path: target }` and stay armed.
* `release()` → if armed, remove the lock file (ignore `NotFound`) and disarm; already-disarmed is
  `Ok(())`.
* `impl Drop for RefLock` → if armed, remove the lock file, ignoring errors (the doc requires it;
  this is not a new public item).

## `loose.rs` read/delete/list half

Shared: the ref file path is `name.file_path(git_dir)`. **Bound every read at 64 KiB** (`Read::take`);
a longer file is `Error::Message(format!("ref file {} is larger than 64 KiB", path.display()))`.
Map `NotFound` → `RefNotFound { name: name.as_bstring().clone() }`; other IO → `IoAtPath`.

* `read` — open, bounded read, `parse_ref_file`. **Never follow symlinks** (`OpenOptions` without
  following? use `symlink_metadata` first and treat a symlink as absent/IO error — pick one and say
  which in the report).
* `try_read` — `read`, mapping `RefNotFound` to `Ok(None)`; every other error propagates.
* `read_ids` — bounded read; `NotFound` → `RefNotFound`; split on `\n`; strip one trailing `\r`;
  skip blank lines; every other line must be a full-width id → `ObjectId::from_hex` (map its error
  to `InvalidHex` as-is); empty file → empty `Vec`.
* `exists` — `symlink_metadata(path).is_ok()` semantics (a broken/corrupt file still exists).
* `delete` — `remove_file`; `NotFound` → `Ok`; other IO → `IoAtPath`. Then prune empty parent
  directories upward, stopping at `git_dir`; a failure to prune is **not** an error.
* `lock_path` — ref path + `.lock`.
* `list(git_dir, prefix, format)` — recursive walk of `<git>/refs` without following symlinks
  (`symlink_metadata`; skip symlink entries and non-regular files). Also consider **top-level files**
  in `git_dir` whose relative name validates (pseudo-refs). For every candidate: build the relative
  ref name, require `name.as_bytes().starts_with(prefix)`, `RefName::parse` (skip invalid names, do
  not fail), then `read()` and push `(name, target)`. Sort by `RefName`. Missing `<git>/refs` is an
  empty list, not an error.
* `list_names` — same walk, no reads: return validated names only, sorted (so a corrupt file still
  appears here but makes `list` fail).
* `parse_ref_file(format, data)` —
  strip one trailing `\n`, then one trailing `\r` (CRLF). Empty → `InvalidRefName { name:
  BString::default(), reason: "empty ref file" }`. Starts with exactly `b"ref: "` → the rest must
  parse as a `RefName` (propagate its error) → `Symbolic`. Otherwise the value must be exactly
  `format.hex_len()` hex digits → `Direct(ObjectId::from_hex(...))`; anything else → the
  `InvalidHex` variant as returned by `ObjectId::from_hex`. `ref:refs/...` (no space) is therefore
  `InvalidHex`, which is what git calls corruption.
* `read_direct` — `read`; `Symbolic` → `Error::SymbolicRef { name: name.as_bstring().clone() }`.
* `read_symbolic` — `read`; `Direct` → `Error::SymbolicRef { name: ... }`; `Symbolic(t)` →
  `Ok(t.as_bstring().clone())`.

## Tests

Add `#[cfg(test)] mod tests` to both files (neither has one), plus a differential test file
`crates/rivet-core/tests/refs_git_differential.rs`. Use `tempfile::TempDir`, `Command::new("git")`,
and skip with a message if `git --version` fails. Drive git with
`git init`, `git update-ref`, `git symbolic-ref`, `git for-each-ref`.

1. `ref_file_bytes_match_git` — `git update-ref refs/heads/main <HEAD>`; compare
   `RefTarget::Direct(id).to_bytes(Sha1)` to the file bytes. `git symbolic-ref HEAD refs/heads/main`
   → `HEAD` parses as `Symbolic(refs/heads/main)` and `to_bytes` equals the file.
2. `read_and_try_read_agree` — existing ref → `Direct`; missing → `RefNotFound` / `Ok(None)` /
   `exists == false`.
3. `parse_ref_file_edge_cases` — direct with `\n`, without newline, with `\r\n` all parse; empty →
   `InvalidRefName`; `ref:refs/x` → `InvalidHex`; short hex and 41 hex → `InvalidHex`; a symbolic
   target that is not a valid ref name → `InvalidRefName`.
4. `read_ids_handles_multiple_and_blank_lines` — write `MERGE_HEAD` with two ids and a blank line;
   equal to the two ids; empty `MERGE_HEAD` → empty vec.
5. `read_direct_and_read_symbolic_mirror` — direct ref: `read_direct` ok, `read_symbolic` errors;
   symbolic ref: reversed.
6. `list_matches_git_for_each_ref` — create `refs/heads/main`, `refs/heads/feature/x`,
   `refs/tags/v1`, `refs/remotes/origin/main`; compare `list(git_dir, b"", Sha1)` names with
   `git for-each-ref --format=%(refname)` (the git output has no top-level pseudo-refs; assert the
   refs/ subset matches and that `HEAD` appears in the rivet list). Add a `refs/heads/x.lock` junk
   file and assert it is skipped.
7. `list_names_sees_corrupt_refs` — write junk into `refs/heads/broken`; `list_names` includes it,
   `list` returns an error.
8. `delete_is_idempotent_and_prunes` — delete `refs/heads/feature/x`; the `feature` directory is
   gone; a second delete is `Ok`.
9. `lock_lifecycle` — `acquire` creates the `.lock`; a second acquire is `LockHeld`; drop removes it;
   `write_and_commit` moves the bytes and leaves no lock; `commit` without a write yields an empty
   ref file; `release` removes the lock; acquiring a ref in a missing namespace creates parents.
10. `symlink_ref_is_skipped_by_listing` (Unix) — symlink `refs/heads/link` → a file outside; `list`
    and `list_names` do not include `link`.

Tests must fail if the to_bytes newline, the `.lock` exclusivity, or the CRLF rule is removed.
